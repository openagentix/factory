# Adopters

This file lists organisations and people who run OpenAgentix Factory and agree to be named. It helps new users see who else uses it, and it is one of the signals a foundation asks for.

**Today the list is empty.** The project has no release yet and nothing in it has been proven by a run. We will not list anyone who has not asked to be listed.

## How to add yourself

Open a pull request that adds one row to the table. Sign off your commit (`git commit -s`, see [CONTRIBUTING.md](CONTRIBUTING.md)). You can also open an issue and a maintainer will add the row.

- Add only your own organisation, or one you are authorised to name.
- Say how you use it in a short phrase, and the stage: `evaluating`, `development`, or `production`. Be honest. "Evaluating" is a useful entry.
- Keep rows in alphabetical order by organisation.
- You can ask us to remove your row at any time.
