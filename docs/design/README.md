# Design reference

`factory-floor-mockup.html` is the web app design the owner approved. Decision record 0004 makes it the contract for look, words and behaviour, and lists where the real app differs.

It is a mockup. All data in it is made up, and nothing in it is live. It is one self-contained file: open it directly in a web browser. It loads its fonts from a public font host, so without a network it falls back to system fonts. The real app bundles its fonts.

Use the side rail to move between screens, and the button at the bottom of the rail to switch between light and dark.
